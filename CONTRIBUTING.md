# Contributing

Report device/OS/app version, reproduction steps and expected behaviour. Remove private data from diagnostics; never upload pairing credentials, signing keys or chat history.

Run both README verification commands. Preserve Java 1.3 / CLDC compatibility and bounded frame/message sizes. Validate material input/layout changes on hardware when possible.

Contributions are Apache-2.0. Do not submit SDK binaries, borrowed vendor branding or code without a compatible licence.
